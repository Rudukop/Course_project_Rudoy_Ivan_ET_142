# Курсовой проект: Поиск и первичный анализ наборов данных
**Дисциплина:** Введение в проектную деятельность  
**Группа:** ЕТ-142  
**Автор:** Рудой Иван  
**Год:** 2026

В рамках курсового проекта выполнен поиск, отбор и первичный анализ наборов данных четырех различных типов:
- Табличные данные
- Временные ряды
- Изображения
- Текстовые данные
**Для каждого типа данных выбрана прикладная задача ИИ, подобран датасет, реализован анализ на Python и сделаны выводы о качестве данных.**

В каждой папке главы находится:
- Jupyter notebook с кодом анализа
- README.md с описанием датасета и результатов
- Загруженный датасет
